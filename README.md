# Cozy Focus Space

Design a beautiful, immersive lofi productivity web app centered around a customizable Pomodoro timer, inspired by the calm, spatial, atmospheric feeling of Wonderspace.app — but with an original visual identity.

Overall Concept

Create a cozy “focus space” dashboard where users can work, listen to music, manage tasks, and stay connected with friends while studying or working.

The experience should feel like entering a personal digital room rather than using a traditional productivity dashboard.

Visual Direction

- Aesthetic: lofi, cozy, dreamy, minimal, atmospheric, calming

- Strong use of depth, soft gradients, glassmorphism, subtle blur, and translucent panels

- Animated ambient background that feels alive but never distracting

- Background should be changeable/customizable

- Include presets such as:

  - Rainy Tokyo apartment

  - Cozy bedroom at night

  - Café during sunset

  - Forest cabin

  - Ocean at night

  - Neon cyberpunk room

  - Cloudy afternoon

  - Study desk with warm lamp

- Allow users to upload/select their own background

- Add subtle animations: rain falling, clouds moving, window reflections, floating particles, candle flicker, leaves moving, etc.

- Animations should be slow and relaxing

- Provide a Reduce Motion option

Main Dashboard Layout

Use a spacious desktop-first layout with three main areas:

1. Left — To-Do List

A compact, elegant task panel.

Features:

- “Today” heading

- Add task button

- Task input

- Checkbox-based task list

- Drag-and-drop task ordering

- Priority indicator

- Optional task deadline

- Show Pomodoros assigned to each task

- Progress indicator such as "3 / 5 tasks completed"

- Completed tasks collapse into a subtle section

- Allow users to start a Pomodoro directly from a task

Example:

TODAY

○ Finish project proposal       🍅 2

○ Read Chapter 4                🍅 1

○ Reply to emails               🍅 1

✓ Review notes                  🍅 2

2. Center — Pomodoro Focus Area

Make this the visual centerpiece.

Display:

- Large circular or softly rounded Pomodoro timer

- "25:00"

- Current mode: Focus

- Current task underneath

- Start / Pause button

- Skip button

- Reset button

- Progress ring around timer

- Small session counter: "Pomodoro 3 of 4"

- Long break after 4 sessions

Allow users to customize:

- Focus duration

- Short break

- Long break

- Number of Pomodoros

- Auto-start breaks

- Auto-start focus sessions

- Timer sound

- End-of-session animation

Include modes:

"Focus · Short Break · Long Break"

When the timer starts, the interface should subtly transform:

- Background becomes slightly darker

- UI distractions fade

- Timer becomes more prominent

- Ambient animation continues

- A tiny “Focus Mode” indicator appears

Friends / Social Focus

Add a Friends Focus feature that lets users connect their Pomodoro sessions with friends.

Create a small floating panel or right-side section called:

“Focus Together”

Show:

- Friend avatars

- Online/offline status

- Current activity

- Current Pomodoro progress

- Session number

Example:

FOCUS TOGETHER

🟢 Maya

   Focusing · 18:42 remaining

🟢 Alex

   Short break · 03:21

⚪ Sam

   Offline

        + Invite Friend

Allow users to:

- Invite friends into a focus room

- Start a shared Pomodoro session

- See friends' timer progress

- Send subtle reactions such as ☕ 🌱 🔥

- See a shared session progress bar

- Join/leave focus rooms

- Create private focus rooms

Avoid making it feel like a social media feed. The social feature should remain quiet, supportive, and distraction-free.

Integrate a beautiful Spotify-style music widget on the right side.

The widget should feel embedded into the environment rather than looking like a generic music player.

Display:

- Album artwork

- Song title

- Artist

- Play/pause

- Previous/next

- Progress bar

- Volume

- Spotify icon

- “Open in Spotify” button

- Lofi Beats

- Deep Focus

- Rainy Night

- Coffee Shop

- Piano Study

- Late Night Coding

The Spotify widget should be collapsible so users can hide it when they want a distraction-free interface.

Ambient Background Controls

Create a subtle floating Environment control.

Users can:

- Change background

- Adjust background brightness

- Adjust animation intensity

- Enable/disable rain

- Enable/disable ambient particles

- Adjust blur

- Change color mood

- Toggle soundscape

Possible moods:

"☀ Morning · ☁ Cloudy · 🌆 Sunset · 🌙 Night"

Include a beautiful full-screen background preview when selecting environments.

Navigation

Keep navigation extremely minimal.

Top-left:

App logo + “FocusSpace”

Top navigation:

- Focus

- Tasks

- Friends

- Stats

Top-right:

- Background / Environment button

- Sound button

- Settings

- User avatar

Avoid traditional heavy sidebars.

Microinteractions

Make the interface feel premium through subtle motion:

- Timer progress smoothly animates

- Buttons gently scale on hover

- Cards have slight parallax movement

- Background transitions crossfade when changed

- Completing a task creates a tiny satisfying animation

- Pomodoro completion produces a subtle ambient celebration

- Friend joining a focus room creates a soft notification

- Spotify album artwork gently moves while music is playing

Do NOT use excessive bouncing, flashy gradients, or distracting animations.

Responsive Design

Desktop:

- Large immersive background

- Three-column layout

- Center timer dominates

- To-do list on left

- Spotify + Friends on right

Tablet:

- Two-column layout

- Spotify/Friends become collapsible panels

Mobile:

- Timer becomes the primary screen

- Tasks accessible through bottom sheet

- Spotify becomes a compact mini-player

- Friends accessible through a floating button

- Background remains full-screen

UI Components

Use:

- Rounded cards

- Soft shadows

- Frosted glass panels

- Thin borders

- Elegant typography

- Large whitespace

- Subtle gradients

- Smooth 200–400ms transitions

- Lucide-style minimal icons

Suggested typography:

- Primary: Inter / Geist / Manrope

- Optional display font: a soft modern serif for atmospheric headings

Color System

Default theme:

- Deep charcoal / midnight background

- Warm cream text

- Muted lavender

- Dusty blue

- Soft peach

- Warm amber accent

The UI should automatically adapt its accent colors based on the selected background.

Provide:

- Dark Lofi

- Light Lofi

- Midnight

- Sunset

- Forest

- Monochrome

Important UX Principle

The product should feel calm, not corporate.

Avoid:

- Dense dashboards

- Excessive borders

- Bright notification colors

- Gamification overload

- Too many buttons

- Conventional productivity-app aesthetics

Think:

“A cozy room where I go to focus.”

rather than:

“A productivity management dashboard.”

Final Visual Goal

The first screen should immediately communicate:

“I want to stay here and focus.”

Create a cinematic, atmospheric interface with a beautiful animated lofi environment, a prominent Pomodoro timer, simple task management, quiet social accountability, and an integrated music experience.

The interface should feel like a combination of:

lofi study room + personal workspace + Pomodoro timer + Spotify + quiet virtual study room.

Prioritize visual polish, atmosphere, usability, and calmness over feature density.
